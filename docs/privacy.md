# pikapik Privacy Policy

pikapik has no developer-run analytics or tracking.

- No analytics, no advertising, no tracking, no account.
- Your settings and Pet progress stay on your Mac. If a signed build offers optional iCloud settings sync and you enable it, those settings use your own Apple iCloud account.
- Keyboard, mouse and window events are handled in memory to run the feature you turned on. They are never stored or sent.
- If you turn on App Volume, the sound of an app whose volume you change passes through pikapik on your Mac while it plays. It is processed on the fly, never recorded or saved, and never sent anywhere. The microphone is never used.
- Brightness levels you set for your monitors are stored only on this Mac. pikapik talks to a monitor only over its display cable and sends nothing anywhere.
- The size you choose for each monitor in Displays is stored only on this Mac. pikapik does not send it anywhere.
- Speed Test is available only in the Direct/GitHub version. When you start a check, it runs macOS networkQuality against Apple's measurement servers; the service receives the network connection information needed for the test. The last result stays on this Mac. The App Store version contains no Speed Test or Cloudflare measurement client.
- The App Store build uses Apple's StoreKit to request available tip products. No products are currently configured, so the tip section stays hidden. Any future optional tips will not unlock features; no purchase or subscription is required.

Questions: open an issue at https://github.com/dev-pikapik/pikapik/issues
